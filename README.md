# 🚀 SP Language Engine

**SP Language** ek simple aur custom mini programming language hai jise beginners ke liye Python mein banaya gaya hai.

👨‍💻 **Created by:** Shivansh Pandey (Class 8 Student, India)

## ✨ Features
- **Interactive Questions:** Line ke ant mein `?` lagakar user se sawal pooch sakta hai aur jawab ko automatically `ANSWER` mein save karta hai.
- **Dynamic Output:** Save kiye gaye `ANSWER` ko dobara kisi bhi line mein istemal kar sakta hai.
- **Built-in Math Calculator:** Seedhe mathematical calculations (jaise `50*4`) solve karke result dikhata hai.
- **Simple Syntax:** Har command `PRINT=` se shuru hota hai aur `.` (dot) par khatam hota hai.

## 💻 Code Example
```text
<SP>...
PRINT=AAPKA NAAM KYA HAI?.
PRINT=SWAGAT HAI ANSWER.
PRINT=50*4.
<SP>...
```

### 🖥️ Output:
```text
AAPKA NAAM KYA HAI? Shivansh
SWAGAT HAI Shivansh
200
```
